# 020 · Tag 规则

> vault 标签规范。tag 是 Dataview / Base 查询的核心索引，**分类层 = 路径层，主题层 = 跨文件夹复用层**。

## 一、双层 tag 体系

| 维度 | 作用 | 来源 | 示例 |
|------|------|------|------|
| **分类层（type 类）** | 标识笔记状态 / 类型 | 来自文件夹 + `type` 字段 | `收集` `日报` `任务` `模板` `规则` `索引` |
| **主题层（topic 类）** | 标识笔记主题，可跨文件夹复用 | 手动选择 | `AI技术` `Obsidian` `文物保护` |

每篇笔记 = **1 个分类层 + 1~4 个主题层**。

## 二、Tag 规范表

> 避免同义词。**遇到新词先查本表**，无则根据文本内容选取关键词，并随时更新下面的规范表，但注意避免同义词。

| 主分类   | 允许 tag                            |
| ----- | --------------------------------- |
| 通用方法论 | `AI技术` `学习` `知识管理` `设计` `应用` `工具` |
| 设计    | `数字媒体设计` `平面设计` `3D设计`            |
| 品牌商业  | `个人品牌` `商业模式` `营销传播`              |
| 应用开发  | `应用开发` `编程语言` `前端`                |

**反面案例**：
- ❌ `AI`（要用 `AI技术`）
- ❌ `笔记` + `收集`（同义重复）
- ❌ `AI` + `人工智能`（同义重复）

## 三、Tag 添加规则

> **不要简单归因**。读取文件内容，分析主旨 → 选题方向 → 作为 tag。

### ❌ 错误示范

```
文件路径：010-信箱 INBOX/020-收集
文件内容：关于 ComfyUI 视频工作流搭建
错误 tag：['收集']      ← 只看路径不看内容
```

### ✅ 正确示范

```
文件路径：010-信箱 INBOX/020-收集
文件内容：关于 ComfyUI 视频工作流搭建
正确 tag：['收集', 'AI技术', 'ComfyUI', '视频工作流']
```

## 四、命名约定

1. **中文优先**：`文物保护` 而非 `CulturalRelic`
2. **专有名词保留英文 / 品牌名**：`Ragflow` `ComfyUI` `Obsidian` `Openclaw` `Claude`
3. **工具 / 平台首字母大写**：`Ragflow` `Ollama` `PyTorch` `Docker`
4. **概念用通用术语**：`AI技术` `知识管理` `生产力` `设计` `哲学思辨`
5. **不嵌套**：`父/子` 写法禁止，用并列 tag
6. **不重复**：同义 tag 立即合并

## 五、tag 数量与排序

- 最少 1 个，最多 5 个
- 排序：**分类层 → 主主题 → 辅主题 → 工具 / 平台**
- 主题层按"重要性"递减

> 示例：
> ```yaml
> tags:
>   - 收集           # 分类层
>   - AI技术         # 主主题
>   - 提示词工程       # 子主题
>   - Claude        # 工具
>   - 工作流          # 辅主题
> ```

## 六、tag 与文件夹的关系

- tag **不重复路径**：放在 `400-资源RESOURCE/420-览阅/421-书籍/` 的笔记，**不再加** `#资源` tag
- tag **不替代文件夹**：tag 是横切维度，文件夹是主分类
- tag **可重复出现在多个文件夹**：`#AI技术` 在 020-收集 / 400-资源 / 200-工作库 都可能命中

## 七、tag 维护

- 每月一次在 `100-工作台WORKDESK/101-快速学习/` 写一条 tag 复盘
- 发现同义 tag 立即合并
- 新增 tag 类别先在 [[110-草稿箱]] 起草，再迁入本文件

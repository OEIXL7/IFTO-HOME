# 030 · 关联引用规则

> vault 内部所有"链接"行为必须遵循本规范。

## 一、wikilink 基础规范

### 1. 形式

```markdown
[[文件名]]                       # 基础
[[文件名|显示文本]]                # 自定义显示
[[文件名#段落]]                   # 链接到段落
[[文件名#^块ID]]                  # 链接到块
```

### 2. 在 frontmatter 中**必须**用引号包裹

```yaml
related_to:
  - "[[打造第二大脑]]"           # ✅ 双引号 + 双方括号
  - "[[打造第二大脑]]"           # ❌ 缺双引号
  - [[打造第二大脑]]              # ❌ 缺双引号
```

### 3. 路径约束

- ✅ 文件名**不含路径前缀**
- ✅ 同名文件用文件夹区分
- ✅ 含空格的文件夹名用整段 wikilink
- ❌ 禁止 `[[../020-收集/xxx]]` 相对路径
- ❌ 禁止 `[[./xxx]]` 当前目录语法

## 二、`related_to` 字段规范

```yaml
related_to:
  - "[[第一性原理]]"
  - "[[打造第二大脑]]"
  - "[[030-关联引用规则#三、正文内联引用 vs related_to]]"
```

- 每篇笔记 **0~5 条**
- 必须是**已存在且可点击**的链接，杜绝空 `[[]]`

## 三、`related_to` 严谨规则

> **核心原则**：`related_to` 不是必填项。**宁可关联少，不可乱关联**。没有明显关联时保持 `related_to: []`。

### ✅ 应该关联

- 文件内容**直接引用 / 讨论**了某笔记的核心概念
- 文件内容**受到某笔记的启发 / 影响**
- 文件主题**与某笔记高度一致**
- 正文使用了 `[[]]` wikilink 链接到该笔记

### ❌ 不应该关联

| 笔记主题 | ❌ 错误关联 | 原因 |
|----------|------------|------|
| 设计文章讨论商业设计执行 | `[[美学散步]]` | 美学散步是纯审美理论 |
| 个人管理方法论 | `[[打造第二大脑]]` | 内容未提到第二大脑方法论 |
| 设计类内容 | `[[美学散步]]` | 同领域但无具体联系 |
| 知识管理类内容 | `[[打造第二大脑]]` | 同上 |
| 效率类内容 | `[[番茄工作法]]` | 同上 |
| 消费心理类内容 | `[[思考，快与慢]]` | 同上 |

### ✅ 应该关联的正确示范

- 文章明确提到 / 引用了某本书的核心观点 → 关联该书
- 文章内容与某本书主题高度契合（如「消费升级的内驱力」与「思考，快与慢」） → 关联
- 内容**只是主题相关但没有具体联系** → **不关联**

## 四、正文内联引用 vs `related_to`

| 场景 | 用法 |
|------|------|
| 正文里**直接讨论**某笔记的观点 | 正文内联 `[[xxx]]` |
| 主题相关但**正文未展开** | `related_to` 字段 |
| 一次性的"参见" | 正文 `[[xxx]]` 即可 |
| 整章系统引用 | 段落级 `[[xxx#章节]]` |

## 五、嵌入（Embed）规范

```markdown
![[xxx.base]]                # 嵌入 Base 视图
![[xxx.md]]                  # 整篇嵌入
![[xxx.md#段落]]             # 嵌入指定段落
![[image.png]]               # 嵌入图片
![[xxx.pdf#page=3]]          # 嵌入 PDF 指定页
```

### 使用规则

- **首页 / 索引页**用 `![[xxx.base]]` 嵌入 Base 视图
- **正文笔记中**禁止用 `![[xxx.md]]` 整篇嵌入
- 图片用 `![[]]` 嵌入，**禁止** Markdown `![]()` 相对路径
- 嵌入 PDF 用 Obsidian 1.5+ 的官方语法

## 六、Base / Dataview 引用规范

### Base 文件命名

- 路径：`900-数据库/990-BASE/`
- 命名：`<编号>-<视图名>.base`
- 一个文件夹对应**一个或多个** base 文件

### Base 视图配置

- 必含 `filters`：限定 `file.folder`
- 必含 `order`：至少 `file.name` + `file.ctime` / `file.mtime`
- 卡片视图必须设 `cardSize` 与 `imageAspectRatio`

### Dataview 引用

- 单条记录用 `LIST` / `TABLE` block
- 复杂聚合用 `dataviewjs` block
- 涉及日期计算必须 `date(today())`

## 七、引用失败处理

| 现象 | 处理 |
|------|------|
| 链接跳到"新建"页 | 修正文件名 / 路径 |
| 链接变红 | 检查大小写、空格、隐藏后缀 |
| 嵌入 base 视图空白 | 检查 base `filters` 与文件夹 |
| 双链图谱断裂 | 用 [[000-Rule总览]] 流程排查 |

# 010 · Frontmatter 规则

> vault 全部笔记的 frontmatter 规范。老格式（`author: JIAXI` / `alias:` / `url:`）继续兼容，新笔记统一使用新格式。

## 一、标准格式

```yaml
---
title: "文件名"
description: "文件描述"
created: YYYY-MM-DD
status: 待整理
tags:
  - 标签1
  - 标签2
related_to:
  - "[[关联文件1]]"
  - "[[关联文件2]]"
---

正文内容...
```

## 二、通用字段表

| 字段            | 类型          | 必填    | 含义                                  |
| ------------- | ----------- | ----- | ----------------------------------- |
| `title`       | 字符串         | ✅     | 文件名（用引号包裹）                          |
| `description` | 字符串         | ⭕ 建议  | 一句话描述                               |
| `created`     | 日期          | ✅     | `YYYY-MM-DD`（**不带时间**）              |
| `updated`     | 日期          | ⭕ 选填  | 最近实质性修改日期                           |
| `status`      | 枚举          | 按目录   | 见 [[040-文件夹专属规则]]                   |
| `tags`        | 列表          | ✅     | 标签，详见 [[020-Tag规则]]                 |
| `related_to`  | wikilink 列表 | ⭕ 选填  | 真正相关的笔记，详见 [[030-关联引用规则]]           |
| `type`        | 字符串         | ⭕ 建议  | 收集/笔记/任务/日报/周报/月报/模板/规则/索引/总结/项目/资源 |
| `place`       | 字符串         | 仅日报周报 | 当日/当周主要地点                           |
| `url`         | URL         | ⭕ 选填  | 原始来源链接                              |

## 三、目录默认 status 速查

| 目录                              | 默认 status |
| ------------------------------- | --------- |
| `000-信箱 INBOX/010-收集`           | `待整理`     |
| `100-工作台WORKDESK/101-快速学习`      | `待整理`     |
| `100-工作台WORKDESK/110-草稿箱`       | `草稿`      |
| `100-工作台WORKDESK/120-项目管理`      | `未开始`     |
| `400-资源RESOURCE/420-览阅/421-书籍`  | `在读`      |
| `400-资源RESOURCE/420-览阅/423-电影`  | `在看`      |
| `400-资源RESOURCE/420-览阅/424-电视剧` | `在看`      |
| 其他目录                            | 不填        |

**已有 status 的不覆盖**（`推进中/已完成/已读/已完结` 都保留）。

## 四、排除目录

> 以下目录**不参与自动化**（跑脚本、加 frontmatter、跑 lint）：

- `900-数据库/910-模板Templates`
- `900-数据库/920-Rule&Skill`

- `000-信箱 INBOX/030-活动清单`
- `000-信箱 INBOX/031-今日待办`

## 五、项目管理属性表（120-项目管理）

```yaml
---
title: "项目任务名称"
description: "任务描述"
created: YYYY-MM-DD
status: 未开始
member: "参与人员"        # 单数，不是 members
end_time: "截止时间"      # 不是 deadline
tags:
  - 项目
  - 主题
related_to:
  - "[[关联项目]]"
---
```

## 六、书籍属性表（421-书籍）

```yaml
---
title: "书名"
author: "作者"
description: "文件描述"
rating: "⭐⭐⭐⭐"
cover: "图片URL"
created: YYYY-MM-DD
status: 在读
type: "书籍类型"
tags:
  - 书评
  - 主题
related_to:
  - "[[相关书]]"
---
```

## 七、字段使用禁忌

- ❌ 单引号包中文（统一双引号或不加引号）
- ❌ 日期写成 `2026/06/15` 或 `2026年6月15日`
- ❌ `tags: ''` / `null` / `none`，空时直接省略字段
- ❌ "标题别名"塞进 `alias` 字段（统一用 `title`）
- ❌ 同一字段出现两次
- ❌ wiki 链接不加引号（必须 `"[[文件名]]"`）

## 八、历史格式兼容

| 老格式                         | 处理                     |
| --------------------------- | ---------------------- |
| `author:                    | 保留兼容（书籍 `author` 字段保留） |
| `alias: 标题`                 | 废弃 → `title`           |
| `created: 2025-09-17 11:28` | 保留兼容，新笔记不再带时间          |
| `url:` 留空                   | 保留占位                   |

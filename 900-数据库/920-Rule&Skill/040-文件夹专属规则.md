# 040 · 文件夹专属规则

> 各主文件夹的专属 frontmatter 字段、典型 tag 组合、文件行为、状态机。

## 一、010-信箱 INBOX

> 唯一信息入口。`status` 默认 `待整理`。

| 子文件夹       | 默认 status | 典型 tag        | 文件行为                               |
| ---------- | --------- | ------------- | ---------------------------------- |
| `010-收集`   | `待整理`     | `收集` + 1~3 主题 | 长文/教程/摘录；整理到 400-资源或 300-领域        |
| `030-活动清单` | —         | —             | checkbox 任务清单；不写 frontmatter（排除目录） |
| `031-今日待办` | —         | —             | 每日待办（排除目录）                         |
| `040-笔记`   | —         | —             | 长线 checkbox（排除目录）                  |


**状态机**：
```
[新建] → 待整理 → 整理中 → 消化完成
                              ├─→ 400-资源RESOURCE
                              ├─→ 300-领域AREA
                              ├─→ 200-工作库WORKFILE
                              └─→ 500-归档资料
```

## 二、100-工作台WORKDESK

| 子文件夹       | 默认 status | 典型 tag    | 文件行为                                                      |
| ---------- | --------- | --------- | --------------------------------------------------------- |
| `101-快速学习` | `待整理`     | 主题层       | 拆解教程；消化完迁 400-资源                                          |
| `110-草稿箱`  | `草稿`      | `草稿`      | 半成品；定期清理                                                  |

**120 项目管理专属字段**：`member` `end_time`，详见 [[010-Frontmatter规则]]。

## 三、200-工作库WORKFILE

| 子文件夹            | 行为                              |
| --------------- | ------------------------------- |
| `201-项目文件/<项目>` | 单一项目所有材料；结题后整体迁 500-归档/520-项目归档 |
| `210-通用模板`      | 公开复用模板；改动需同步更新本文件               |

**项目编号规范**：`201-项目文件/<3 位代号>-<项目名>/<子分类>/`

## 四、300-领域AREA

> 排除目录（不参与自动化处理）。

## 五、400-资源RESOURCE

> 览阅类资源有专属属性表。

| 子文件夹              | 默认 status | 专属字段                                                                     |
| ----------------- | --------- | ------------------------------------------------------------------------ |
| `420-览阅/421-书籍`   | `在读`      | `author` `rating` `cover` `type`，见 [[010-Frontmatter规则#六、书籍属性表（421-书籍）]] |
| `420-览阅/423-电影`   | `在看`      | `rating`                                                                 |
| `420-览阅/424-电视剧`  | `在看`      | `rating`                                                                 |


**览阅类状态机**：
```
[在读/在看] → [已读/已看完] → [补 rating 与心得]
```

## 九、跨文件夹通用原则

1. **路径即分类**：先选对文件夹，frontmatter 只需补充主题维度
2. **状态变化驱动迁移**：从 010-INBOX 到 400 / 300 / 500，必须显式移动
3. **frontmatter 改完同步 tags**：迁移后重新评估 `status` 和 `tags`
4. **防止幻觉**：草稿、AI 生成内容、剪藏摘要中的数字、人名、版本号、引用、结论，未经原始来源或可靠资料核验，不得写入正式资源、规则、索引或对外发布稿
5. **新建子文件夹先更新本文件**：避免出现"无规则孤儿目录"
6. **排除目录清单**（与 [[010-Frontmatter规则#四、排除目录]] 同步）：
   - `910-模板Templates` / `920-Rule&Skill` / `000-索引INDEX`
   - `300-领域AREA` / `600-复盘总结`
   - `010-信箱 INBOX/030-活动清单` / `031-今日待办` / `040-笔记`
